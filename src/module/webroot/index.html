首次使用指南

通过终端启动 AnCLI 或 AI 工具前，请先切换到 root 权限。

1

打开终端程序，输入命令并在 KernelSU 弹窗中授予 root 权限：

su
2

进入 root 终端后，直接输入对应命令启动 Agent：

Codexcodex 反重力agy

需要管理应用或调整配置时，再运行 ancli 打开管理菜单。只使用当前 WebUI 页面不需要另开终端。完整开发环境也可从 GitHub Releases 下载离线包，再从容器安装区选择 ZIP 导入。

Agent 沙盒与权限提示

如果 AI 工具报告沙盒无法启动、命令被沙盒拦截或隔离初始化失败，请在该工具的权限设置中切换运行权限。

1

打开该工具的权限或沙盒设置，将运行权限切换为：

Full Access / 完全访问
2

重新运行刚才的命令。不同工具的设置入口名称可能不同。

Android PRoot 无法提供某些 Linux 沙盒所需的内核隔离能力，安装 bubblewrap 也不能补上缺少的能力。Full Access 会关闭该工具自身的沙盒，请只在信任的工作区使用；它只适用于沙盒隔离导致的问题。

完全初始化环境

此操作不可恢复。它会删除容器中的应用、密钥、配置、skills、Agent 记忆和全部旧日志；Ubuntu rootfs 和 AnCLI 模块文件会保留。
保留清理前的应用清单，在干净 PRoot 中重新安装；不会恢复 API key、代理和应用配置。

删除当前容器

此操作会永久删除完整 Ubuntu rootfs，包括已安装 Agent、软件包、配置、密钥和记忆文件。AnCLI 模块及模块设置会保留。请先退出正在运行的 Agent。此操作无法撤销。

彻底卸载模块本体

⚠️ 危险操作！此操作将完全销毁 AnCLI 的一切数据与插件本体：
1. 卸载并删除所有已安装的命令行工具与 AI Agent；
2. 彻底抹除 Ubuntu 容器系统（/data/local/tmp/ancli）及所有配置、密钥与记忆；
3. 卸载 AnCLI 模块本体（/data/adb/modules/ancli）并移除宿主所有注入脚本。
操作完成后，请立即重启手机以清理内核文件系统挂载。

Agent 全局记忆与环境探测

模块提供面向 AI Agent（AGY、Claude、Grok 等）的全局规范记忆模板（/root/.agents/AGENTS.md）与配套环境检测机制。首次运行时要求 Agent 执行环境探测以自适应本机硬件与挂载边界。请选择是否向容器添加该文件：

卸载应用

卸载后用户数据与密钥将继续保留在容器中，只有再次安装时才会用到。

运行环境修复

将重新配置容器 DNS、修复权限与包装器，统一全局 Skills 规范，并刷新双注入兼容环境。是否立即开始修复？

强制停止安装？

将终止当前安装任务，并清理该任务创建的临时容器文件。已有容器和数据会保留；中断的软件包可能需要修复。

Codex 在 Android PRoot 中的权限设置

Android PRoot 无法建立 Codex 默认命令沙箱需要的挂载隔离，安装 bubblewrap 也不能补上这项内核能力。安装后启动 Codex，在输入框运行 /permissions，选择 Full Access，再重试命令。Full Access 会关闭 Codex 自身的命令沙箱，请只在你信任的工作区使用。
